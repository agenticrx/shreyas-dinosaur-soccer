# Shreyas ELA Adventure

A playful, dinosaur-and-soccer themed ELA learning app for 4th and 5th graders.

## Pages
- Dashboard
- Learning Path
- Reading Lab
- Vocabulary Builder
- Grammar Lab
- Writing Studio
- Quiz Arena
- Progress
- Parent View

## Learning Goals
- Reading comprehension and text evidence
- Main idea, theme, inference, and summarizing
- Context clues and vocabulary
- Grammar, sentence structure, and punctuation
- Narrative, opinion, and informative writing

The app is designed to make practice short, interactive, encouraging, and age-appropriate.
